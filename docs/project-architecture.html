LydiaRX AG Documentation

Project architecture

This page explains how the public LydiaRX site, the technical pages, the DS specifications, and the imported local skill catalog fit together inside one static output.

Repository structure

The repository publishes its output from `docs/`. Public pages, technical pages, shared CSS, partials, assets, and the DS set all live under that root so the result stays deployable without a separate build system.

  • docs/*.html — public routes and technical documentation pages.
  • docs/partials/ — shared header and footer fragments.
  • docs/assets/ — static SVGs and reusable assets.
  • docs/specs/ — DS files and the generated matrix.
  • AGENTS.md — root agent guidance and current skill catalog.
