LydiaRX AG Documentation

Project architecture

This page explains how the public LydiaRX site, the technical pages, the DS specifications, and the imported local skill catalog fit together inside one static output.

Repository structure

The repository publishes its output from `docs/`. Public pages, technical pages, shared CSS, partials, assets, the DS set, and linked research article pages all live under that root so the result stays deployable without a separate build system.

The same output also supports a visual review mode for design exploration. The corner Dev Preview widget is visible by default unless a stored override disables it. Direct ?theme=fusion, ?theme=inspiration, and ?theme=default links still work, and the shared client-side layer presents a browser-storage consent banner for these persisted preferences. The inspiration review theme now uses one shared helix-style point-field engine across its selected white floors, with page, floor, and refresh-level randomisation so every band regenerates a different clustered starting state without changing animation families.

  • docs/*.html — public routes and technical documentation pages.
  • docs/partials/ — shared header and footer fragments.
  • docs/assets/ — static SVGs and reusable assets.
  • docs/specs/ — DS files and the generated matrix.
  • AGENTS.md — root agent guidance and current skill catalog.
